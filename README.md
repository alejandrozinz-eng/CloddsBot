## 🚀 What is CloddsBot?

CloddsBot is a revolutionary open-source AI trading agent that works **for you around the clock**. Built on Claude's advanced AI capabilities, this autonomous system operates across **more than 1000 markets worldwide** - from prediction markets like Polymarket and Kalshi, to crypto exchanges like Binance, Hyperliquid, Solana DEXs, and 5 EVM chains (Ethereum, etc.).

Simply put: **you sleep, CloddsBot trades.** It constantly scans for profitable opportunities, executes trades instantly when it finds an edge, and manages risk automatically so you don't have to watch charts all day.

## 🎯 Getting Started - Your First Trade

Once installed, here's how to start trading with CloddsBot:

1. **Create an account** on your preferred exchange (e.g., Binance, Hyperliquid, or Polymarket)
2. **Generate API keys** inside the exchange dashboard (look for "API Management" or "API Keys" section)
3. **Paste these keys** into CloddsBot's configuration screen (make sure to enable "trading" and "reading" permissions, not "withdrawal")
4. **Select your markets** - choose from polymorphic prediction markets, crypto pairs, or Solana DEXs
5. **Set your risk preferences** - define how much capital to deploy, maximum position size, and daily loss limits
6. **Hit "Start Autopilot"** and watch CloddsBot begin its scan-and-execute cycle immediately

The agent will now continuously monitor hundreds of markets, execute trades when conditions favor you, and manage all open positions automatically. You can check performance anytime via the built-in dashboard - charts, P&L, win rate, and trade history all displayed clearly.

## 🔧 Troubleshooting Common Issues

### "Windows protected your PC" warning
This is normal for open-source software. Click "More info" → "Run anyway" to proceed.

.



### "Connection failed" error
Check your internet connection. Also, ensure your firewall isn't blocking CloddsBot - add an exception if prompted.



### "Invalid API keys" message
Double-check that you copied the keys correctly (no extra spaces). Also verify that you enabled trading permissions, not just read-only.



### Application won't start
Make sure Windows is updated to the latest version. Also try right-clicking the shortcut and selecting "Run as administrator."
